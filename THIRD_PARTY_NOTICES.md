## 2. Haar cascade classifier

* File: `haarcascade_frontalface_default.xml`, created by Rainer Lienhart.
* Provenance: shipped **inside the OpenCV packages**, not by this repository —
  `src/multimodal_auth/preprocessing/face.py` loads it at runtime from
  `cv2.data.haarcascades`.
* License: the XML file's own header carries the *Intel License Agreement for
  Open Source Computer Vision Library* (Copyright (C) 2000, Intel Corporation),
  a BSD-3-clause style license with a non-endorsement clause.
* Attribution: Rainer Lienhart and Jochen Maydt, "An extended set of Haar-like
  features for rapid object detection" (IEEE ICIP 2002).
* Repository action: **do not vendor this file**. Keep loading it from the
  installed OpenCV package, and keep `opencv-python-headless` below 5.x, because
  the 5.x wheels no longer ship `cv2/data/`.

## 3. Datasets

### 3.1 Olivetti / ORL face database — attribution required

* Source: AT&T Laboratories Cambridge, "The Database of Faces" (ORL), collected
  April 1992 – April 1994. Fetched through
  `sklearn.datasets.fetch_olivetti_faces()` (scikit-learn downloads it from a
  mirror, `ndownloader.figshare.com/files/5976027`).
* Original description: `https://cam-orl.co.uk/facedatabase.html`.
* Terms: distributed for research use; "When using these images, please give
  credit to AT&T Laboratories Cambridge."
* Use here: the 50 "stranger" face negatives used to train the shipped models
  (obtained by the frozen script `scripts_pc/00_setup_strangers.py`).
* Repository action: **no Olivetti image is redistributed** in this repository,
  and no derived feature file from it is either (`data/` is gitignored). Anyone
  re-running the training recipe fetches the database themselves and is bound by
  its terms.

### 3.2 Synthetic stranger voices — no third-party rights

25 two-second `np.random.uniform(-0.1, 0.1)` clips generated by
`scripts_pc/00_setup_strangers.py`. They are not speech and contain no person's
data.

### 3.3 The author's own enrolment data — not distributed

5 face photos and 10 voice recordings of the project author, plus their derived
features. They are the raw material of the published genuine/impostor numbers
and are deliberately **not** part of the repository (`data/` is gitignored).

## 4. Examples

`examples/sample_face.jpg` and `examples/sample_voice.wav` are generated by
`examples/make_examples.py` (seed 20260419) from pure numpy drawing and tone
synthesis. They depict nobody and contain no third-party material.

## 5. What is *not* here

* No third-party pretrained model weights: the three networks are self-defined
  and self-trained.
* No OpenCV, PyTorch, ONNX Runtime or librosa source code is vendored.
* No fonts, icons or images with unclear provenance: the repository contains
  exactly two generated example files and no other binary media.
* No NCNN / OpenVINO / TFLite / TensorRT / RKNN artifacts.
